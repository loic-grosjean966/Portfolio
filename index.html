Pipeline CI/CD

Mise en place d'un pipeline CI/CD complet pour automatiser le cycle de vie d'une application. Fonctionnalités incluant :

  • Build automatique à chaque push
  • Exécution des tests unitaires et d'intégration
  • Analyse de la qualité du code (SonarQube)
  • Déploiement automatisé en staging puis en production

Technologies utilisées : GitLab CI, Docker, Ansible, Nginx

Infrastructure as Code

Provisionnement d'une infrastructure cloud complète et reproductible via du code versionné. Fonctionnalités principales :

  • Création de VPC, sous-réseaux et groupes de sécurité
  • Déploiement d'instances EC2 et de bases de données RDS
  • Configuration des serveurs avec Ansible
  • Gestion des états Terraform en remote backend (S3)

Stack utilisée : Terraform, Ansible, AWS, Git

Cluster Kubernetes

Déploiement et orchestration d'une application microservices conteneurisée sur un cluster Kubernetes. Caractéristiques :

  • Conteneurisation des services avec Docker
  • Déploiements, Services et Ingress Kubernetes
  • Auto-scaling horizontal des pods (HPA)
  • Monitoring avec Prometheus et Grafana

Stack utilisée : Docker, Kubernetes, Helm, Prometheus, Grafana
